# ДЗ №7. Написание автотестов с использованием XPath/CSS-селекторов и JUnit

Продолжение проекта ДЗ №4–6 на Java, Playwright и JUnit. Используется сайт [The Internet](https://the-internet.herokuapp.com/)

Тесты проверяют:

- Успешный вход, выход и сохранение авторизации после повторного открытия защищённой страницы
- Ошибки при неверных и пустых учётных данных, успешный вход после исправления пароля
- Начальные состояния чекбоксов, их переключение и возврат в исходное состояние
- Выбор пунктов выпадающего списка, добавление и удаление элемента

Тесты находятся в `src/test/java/tests`. Один старый тест чекбокса отключён через `@Disabled`, поскольку заменён динамическими проверками всех чекбоксов

Для запуска нужны JDK 17 или новее и Maven. Команды выполняются из корня проекта

Установка Chromium перед первым запуском:

```bash
mvn test-compile exec:java -Dexec.args="install chromium"
```

Запуск всех тестов без отображения окна браузера:

```bash
mvn clean test
```
